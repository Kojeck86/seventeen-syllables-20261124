# Seventeen Syllables of Debugging

This entry writes one haiku about debugging to `/output/entry.txt`: three short lines in the 5-7-5 syllable shape, a cursor blinking at three in the morning, a stack trace scrolling past midnight, and a last line that turns the whole night's hunt back on the debugger. The program uses only the Python standard library and always writes the same text, so the entry is byte-identical on every run.

> cursor blinks at three
> a stack trace scrolls past midnight
> the bug was mine
